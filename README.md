# Intelligent-Web-Scraper-using-LLM

This project is a web-based application that allows users to input a URL, from which the system scrapes content using a web scraper. The extracted information is then processed and fed into a chatbot powered by a large language model (LLM). The chatbot enables users to ask questions and receive context-aware answers based on the content scraped from the provided webpage. The overall goal is to create an interactive interface where users can easily extract and query web content in natural language.
